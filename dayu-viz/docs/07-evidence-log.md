├── M<N>/

### 无效探针（必须记录，否则会误导后续会话）

| # | 探针写法 | 症状 | 为什么无效 |
| --- | --- | --- | --- |
| 1 | 把 `EventSource` 替换成一个只存 handler、**从不派发事件**的桩 | 页面"未重渲染"，看似代码有 bug | 桩不派发事件，`refresh()` 结构上不可能被调用；这是**测试自身不可能失败的假阴性** |
| 2 | 继承 `globalThis.EventSource`（以为 Node 24 有全局实现） | `Node 无全局 EventSource` | Node 24 该 API 仍属实验特性，未默认暴露 |
| 3 | 自建 SSE 客户端但未处理相对 URL | `ERR_INVALID_URL: '/events'` | 浏览器以页面为基解析相对 URL，Node 没有基 |

修正后（真实 SSE 客户端 + 补 base URL）才得到 `UI-02b` 的 432 ms 结论。

> **教训**：这三条都属于本规范反复强调的「假证据」——尤以第 1 条为甚：一个不可能失败的测试与"没有测试"等价，而它的绿色会被误读成"已验证"。
