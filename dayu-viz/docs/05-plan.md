# 里程碑与 Definition of Ready

> 节点定义**不是工期承诺**。当前状态：`M0` 进行中；`M1`–`M5` 未开始。
> 关联：`01-decisions.md`、`docs/contracts/`、`06-test-matrix.md`

## 1. 节点序列

| 节点 | 名称 | 状态 |
| --- | --- | --- |
| `M0` | 可测试需求与决策基线（**不是可用软件**） | 进行中 |

## 2. 里程碑卡片

### M0：需求与决策基线

- **用户价值**：后续编码有合法基线——每条需求可单独引用，每个待决项写明卡在谁那里、最迟何时。
- **入口**：设计文档 `docs/superpowers/specs/2026-10-11-dayu-viz-dashboard-design.md` 获用户"方案认可"（`D1`–`D5`，2026-10-11）。
- **交付**：本项目 `docs/` 的 M0 基线内容、`R01`–`R09` 清单、`Q01`–`Q04` 登记、`M0`–`M5` 节点轴、`G1`–`G3` 验收门槛。
- **测试策略**：D 类（文档结构与来源审查）。
- **适用用例**：`D-M0-01`。
- **演示脚本**：打开 `docs/00-index.md` 一屏读完阶段/节点/阻塞/待批准/下一步；失败场景：故意把某条 `Q` 的状态列清空，审查时必须判为不合格而非默认已批准。
- **出口判据**：每条 `R` 可被单独引用；每个 `Q` 写明"卡在谁那里 / 最迟何时"；`05-plan.md` 每张卡含「明确未交付」与「不算完成」；`00-index.md` 不超过 60 行。
- **明确未交付**：**任何可运行软件**（无服务、无解析器、无页面）；`06-test-matrix` / `09-acceptance` / `10-delivery` 的实际内容。
- **不算完成**：把设计文档当成已实现；把 `R` 清单写全但没有 DoR 核查；`00-index.md` 抄模板示例文件当成本项目地图。

## 3. Definition of Ready

故事开工前七条全中：

- [x] 1. 一个可演示的用户结果，对应 `R` 编号；**明确不包含什么** — M1 首个可演示行为："启动服务指向任意 dayu 项目目录，一屏读出阶段、当前节点、阻塞项与待批准项"，对应 `R01`/`R03`/`R04`/`R07`/`R09`；**不包含**图表视图 V2–V6、不包含 agent 协作、不包含任何写回。
- [x] 2. 正常/边界/失败用例及预期；T/C/H/D 已分类 — T：解析纯函数先写断言见 RED；C：合成 fixture 契约测试；H：浏览器人工核对视图；D：使用说明。失败用例：无 `docs/` 目录 → 可识别缺失；模板占位 `<...>` → `unknown` 而非 0；文档损坏 → 该文档降级 `unknown` + warning，不整体失败。
- [x] 3. 依赖的 `Q` 项已决议；字段/阈值/数据来源已冻结到**足够测试** — `Q01` 非 M1 所需；`Q02` 最迟 `M2` 前、`Q03` 最迟 `M4` 前、`Q04` 最迟 `M5` 前，均不在 M1 到期；字段来源见设计文档 §6 数据模型与 §7 解析契约；数值门槛为 `G1`–`G3`。
- [x] 4. 夹具、环境、可观察输出、清理方法可用；需费用/高风险动作已获**明确授权** — 夹具为 `test/fixtures/sample-project`（合成，脱敏，不拷真实项目文档）；环境 Node v24.16.0；可观察输出为 V1 驾驶舱字段与 `meta.warnings`；清理=无副作用（只读）；无费用、无高风险动作，`git push` 不在本节点。
- [x] 5. 入口/出口、副作用所有权、取消/重试/去重、资源限额明确 — 入口 `npm start -- --project <dir>`；出口=页面渲染出模型；副作用所有权：解析器永不写文件（`R02`），唯一读盘集中在 `src/server/project.mjs`；取消/重试=重新解析全量模型，SSE 断线由客户端重连，不需要去重；资源限额=单机本地、无外部调用。
- [x] 6. 能识别 RED 失败原因；上游探索与业务测试分开 — RED 必须因业务规则缺失而失败，模块不存在/工具未装/网络断开**不构成 RED**；本节点无上游 spike 混入，探索性内容不进入用例。
- [x] 7. 与现有系统的兼容范围明确；有失败后的停止/恢复方案 — 兼容范围：只读消费 dayu 既有 `docs/` 文档集，不改动被观察项目；失败停止方案：字段缺失降级 `unknown`；若真实文档格式漂移（`B01`）导致无法解析，**停止推进并回到设计文档评审**，不静默降低需求。

> **未知能力先进入限范围 spike**，不在未验证假设上批量编码。
> spike 出口可以是"不支持"，但**不算功能交付**——返回设计，**不静默降低需求**。
