# 证据日志

> 只追加，不涂改历史。已记录的证据保留**原始日期与验证范围**；
> 修正以新增条目表达（"原表述 X 不精确，已修订为 Y，原因 Z"）。

## 目录组织

```
evidence/
├── M<N>/
│   ├── <用例ID>/
│   │   ├── manifest.json     ← 版本/哈希/构建参数
│   │   ├── result.txt        ← 结果
│   │   ├── red.txt           ← RED 命令 + 退出码 + 断言
│   │   └── artifacts/        ← 日志、截图、录像（已脱敏）
```

> 没有版本控制提交时，用**内容哈希**标识版本。
> **不为满足形式而擅自提交或发布仓库。**

## T 类故事证据

| 字段 | 内容 |
| --- | --- |
| 需求 ID | `R…` |
| 契约 ID | `C…` / `A…` |
| 用例 ID | `<域>-…` |
| 待测组件 | <模块/函数> |
| 输入 fixture 版本 | <来源 + 哈希> |
| **RED** | 命令 / 退出码 / **断言** |
| **GREEN** | 命令 / 结果 |
| 代码版本 | <提交哈希或内容哈希> |
| 相关回归 | <跑了哪些、结果> |
| 人工/实机证据 | <路径；H 类必填> |
| **残余风险** | <这次没覆盖到什么> |

> **RED 必须因缺失/错误的行为而失败。**
> 模块无法导入、工具未安装、凭据缺失、网络断开**都不构成 RED**。
